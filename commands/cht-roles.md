# /cht-roles — 八视角过一遍

## 参数

| 参数 | 作用 |
|---|---|
| `<角色名>` | 只跑一个视角：ceo / pm / arch / design / eng / review / qa / ship |
| `--all` | 八个视角全跑，每个 2 分钟 |
| `--ui` | 额外跑设计七维度打分 |

## 执行

按 `references/08-roles.md` 逐角色问那**一个**问题，并给出该视角的判断：

```
[CEO]   值得做吗：<是/否/缩小>  理由：<一句>
[PM]    验收可测吗：<哪条不可测>
[架构]  未验证假设：<具体一条>
[设计]  最差维度：<维度 X = 5/10>，改法：<一句>
[工程]  任务可验证吗：<哪个任务缺验证>
[评审]  最可能炸点：<文件:行 + 场景>
[QA]    有证据吗：<缺哪条证据>
[发布]  回滚要几分钟：<答案>
```

每个角色都要给**结论**，不能只说"看起来还行"。

## 规则

- 每个视角**只问自己的那一个问题**，不越界
- 有否决权的角色给出否定时，要指名具体的阻塞项
- `--all` 时不要重复同一个发现八次，合并同类项

## 输出

一张表 + 一句总判断：

```
总判断：可以进 <下一阶段> / 需先解决 <N> 个阻塞项
```
